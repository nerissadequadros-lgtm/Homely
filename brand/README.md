# Identidade visual · Homely

**Nome:** Homely  
**Assinatura:** Seu celular. Seu universo.  
**Voz:** acolhedora, direta, criativa. Convites curtos: “Seu espaço”, “Continue se inspirando”, “Seu estilo, do seu jeito”.

Marca: casa com abertura central; casa representa o espaço pessoal e a tela inicial. Desenho vetorial com traços arredondados, reproduzido em Canvas/VectorDrawable para manter nitidez. Não usa moldura de iPhone ou Dynamic Island no app Android.
